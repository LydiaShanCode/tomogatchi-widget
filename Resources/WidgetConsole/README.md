# Small widget console art

mini-console.png is the approved blue EAT/star console, copied unchanged from
its generated original. The renderer removes transparent margins by viewport,
fitting the outer shell to a square. It does not copy the reference phone wallpaper.

Required original nature PNGs (not yet available as workspace files):
- nature-hill.png — first green hill reference (default)
- nature-golden-hills.png — golden hills reference
- nature-desert.png — red desert reference
- nature-mountains.png — green mountain ridge reference

Use the supplied originals, without generated replacements. Layer order inside
the screen: landscape photo → white at 40% opacity → unchanged photographic head
and abstract sprite. The white overlay never washes out the character or casing.
Missing photos produce an explicit placeholder until the originals are imported.

EAT and star have transparent App Intent hit targets over the artwork's buttons.
They open the app for gift acceptance/dancing; widgets do not run continuous loops.
Landscape selection is local to the device and shared through the signed App Group.
